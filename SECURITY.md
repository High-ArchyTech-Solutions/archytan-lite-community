# Reporting a vulnerability

Please report security problems in Archytan Lite privately, not in a
public issue:

- use **Report a vulnerability** on this repository's
  [Security tab](https://github.com/High-ArchyTech-Solutions/archytan-lite-community/security), or
- email contact@high-archy.tech.

Include the image version you ran (the tag you pulled), what you did, what
happened, and what you expected. Leave out real tokens and signing keys.

We will acknowledge your report, keep you informed while we investigate,
and credit you in the advisory if you would like to be named. Fixes ship as
a new image version, announced in this repository's release notes and its
security advisories. To hear about them, watch this repository and choose
*Custom → Releases* and *Security alerts*.
